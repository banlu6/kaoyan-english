# 考研英语真题 · 微信小程序

> 小程序已于 2026-09 之后改名；本仓库标题仍是旧代号。**对外物料（视频、推文、海报、配图）一律不出现小程序名称**，入口只放小程序码。

一个**纯本地运行**的考研英语真题小程序，核心场景是**横屏做阅读理解**：左题右文（题目区可拖拽加宽 / 可收起）、双击记词（文章/题干/选项通用）、长按看释义、题卡可拖动可缩成悬浮签、目录可跳转、提交即出解析。

> 全程**不发起任何 `wx.request` 网络请求**，无需服务器、域名与备案。题库与词库均打包在小程序内。
> 覆盖**英语一 / 英语二**（2010–2026，阅读理解 + 完形填空）与**四级 / 六级**（2015–2026，仔细阅读），共 **437 篇 / 2695 题**。

## 一、功能清单

### 首页 `pages/home`
- 顶部标题 + 统计（已完成篇数 / 生词数）
- 功能入口：**单词本**、**导出错题**、**设置**、**使用教程**（首次打开会自动弹出一次教程）
- **继续上次**：记录最近打开过的篇目，一键回到
- 卷种 Tab：**英语一 / 英语二 / 四级 / 六级**
- 年份列表（按年份倒序），点击展开该年篇目；考研 2010–2026，四六级 2015–2026（含同一年多套）
- 篇目按题型分组（考研：**阅读理解 Text 1–4** / **完形填空**；四六级：**仔细阅读 Passage 1 / 2**，同一年多套），显示题数与完成状态（`✓ 正确数/总数`、`进行中`）

### 横屏做题页（核心组件 `components/exam-reader`）
- **阅读方向**：页面声明 `"pageOrientation": "auto"`，运行时按设置调用 `wx.setPageOrientation`（未支持时静默降级、靠 auto 跟随手机旋转）；**「设置 → 阅读方向」可切横屏精读 / 竖屏阅读（默认横屏）**。竖屏为**上下分栏**：上「文章」、下「题目」两块**同时可见**，中间横向分隔条可**拖拽调整题卡区高度**（夹取在 120px – 主体 70%），逻辑与横屏一致；布局用 `flex` + `vh/vw`
- **布局：左题右文** —— 题目面板在左侧；**拖拽面板右边界**可动态调整题卡区宽度（夹取在 30%–70%），分隔条命中区 14px、全段都能拖
- **分隔条正中一个按钮两种手势** —— `⟨` 收起按钮就在分隔条**正中**（34px 大圆点）：**轻点＝收起题目面板**；**按住拖动＝调整宽度**。两者互不抢占（轻点不会误拖、拖动松手不会误收起）
- **题目面板可收起成小悬浮窗** —— 轻点分隔条正中的 `⟨`，题目面板整块隐藏、文章占满全宽；原位置留一个**可拖动的小悬浮窗**（显示当前题号），拖到任意角落不挡阅读，**单击悬浮窗**即可展开面板
- **逐句中译按需展开** —— 文章**每一句**、**题干**、**每个选项**末尾都有一个「译」小按钮，点开只显示那一句/那一项的中文，再点收起。默认不显示任何中文，需要时再查
  - 题库只有「段落级」译文：中英句数一致时逐句对齐；不一致时该句兜底显示**整段**译文（不做按比例硬切，避免错位编造）
- **页内字号调节**：顶栏 **Aa** 直接在阅读页弹出字号浮层（文章字号 / 题目字号 / 行距），**拖动即实时预览**，松手写入设置；与原「设置页」并存
- **文章区**
  - 段落按词切分渲染；**双击**单词 → 加入生词本（全文同一词的各词形标红虚线 + 轻振动 + 提示）；**再次双击同一词 → 取消**（移出生词本、取消标红）；**单击不做事**
  - **长按**单词 → 弹出释义卡片（音标 / 词性 / 释义 / **本文例句** / ＋加入·再点取消生词本）；**释义过长时卡片中部可上下滚动**，头部与按钮固定不滚
  - **题干与选项同样支持双击/长按取词**：与文章完全一致；选项内取词不会误选中该选项
  - 已在生词本的词以朱红虚线标识，且随生词本增删**实时更新**（含其所有词形，如 `donkey`/`donkeys`/`donkey's` 同归一条）
  - 「取词模式」关闭时整段纯文本渲染，长文更流畅（可在设置中切换）
- **题卡区**
  - 每题一张卡片，**绝对定位 + 可拖动**（拖动把手为卡片标题栏），限制在容器内
  - **内容超一屏时右下角出现「⌄ 题目可下滑」提示**，滚动后自动消失；滚到底时「提交本题」按钮完整可见（scroll-view 尾部有占位块补足微信 padding-bottom 不计入滚动范围的坑）
  - **每张卡可单独缩成小悬浮签**：点标题栏的 **`─`**（按下即收起，无需点准 tap），整卡收成胶囊（只剩「第 N 题 · 点开 ▸」），可继续拖动挪位；**轻点胶囊**即恢复整卡；多卡互不影响
  - `z-index` 点击/拖动时置顶；顶栏 **⟲** 一键复位所有卡片位置
  - 选项 `[A][B][C][D]` 可选中；提交后正确项绿底、选错项红底并标注「你的选择」
  - 提交后展开解析：`【题型】`、定位段（第 N 段 + 原句 + 译文）、解析行、逐选项判定（✓正确 / ✗干扰项标签 + 说明）
  - `answer === -1`（数据缺失）时只提示「本题答案缺失，暂无法判对错」
- **目录抽屉 `toc-drawer`**：`☰ 目录` 打开，宽约 `38vw`，含**段落目录**（P1…Pn + 首 20 字预览）与**题目列表**（题号 + 题干预览 + 已答状态）；点段落定位滚动，点题号高亮该卡
- **底部条**：上/下题切换、题号进度、**提交全部**、**清空作答**
- 作答实时持久化，退出再进自动恢复

### 单词本 `pages/vocab`
- 列表：单词 / 音标 / 词性 / 释义 / 来源篇目 / 添加日期 / **掌握度标签**（生疏 · 模糊 · 熟悉，点击循环切换）
- 长按或 ✕ 按钮删除（二次确认）
- 顶部搜索框（按单词或释义过滤）+ 按**卷种 / 年份**筛选 + 总数显示
- **导出**：拼接为文本复制到剪贴板（`wx.setClipboardData`）

### 错题本（导出错题）
- 提交判分时**答错的题自动进入错题本**（本地缓存摘要：卷种 / 年份 / 篇目 / 题号 / 题干 / 你的答案 / 正确答案）
- 首页「**导出错题**」入口：一键把全部错题拼成纯文本**复制到剪贴板**，可贴到笔记、打印或发给自己复习
- 「清空作答」会同步移除该篇的错题记录（重新做，错了会再进）
- 空态引导「去首页开始做题」

### 设置 `pages/settings`
- 文章字号 `14–26`（默认 17）
- 题目字号 `12–22`（默认 15）
- 段落行距 `1.4–2.2`（默认 1.8）
- 显示中文翻译（整段对照）/ 显示选项中译 / 取词模式 / 长按看释义（开关，每项附详细说明）
  - 注：**题干中译不再默认显示**，改由题卡里题干末尾的「译」按钮按需展开；「显示选项中译」只决定选项译文**默认是否已展开**，页内每个选项的「译」按钮仍可单独开关
- 危险操作（均二次确认）：清空生词本 / 清空做题进度 / 恢复默认设置

### 关键架构说明（为什么这样拆）

小程序有两条硬限制：**单包 ≤ 2MB**、**主包页面无法 `require` 分包文件**（反向可以），且 **`setData` 单次 ≤ 1MB**。因此：

- 题库拆为六个分包（`packageEn1` ≈ 1.7MB、`packageEn2` ≈ 1.6MB、四级/六级各按年份拆 Recent + Vintage 两包，均 < 2MB）。
- 采用「**分包薄页面 + 主包共享组件 + globalData 传数据**」：
  - `package*/pages/read/read.js` 在 `onLoad` 中静态 `require` 本分包题库，挂到 `app.globalData.bank[paper]`，随后把 `pid` 以 **property** 传给主包组件 `exam-reader`。
  - 同一卷种的两个分包共用一个卷种 id（如 `cet4`），首页按卷种聚合展示。
  - `exam-reader` 通过 `utils/bank.js` 读取**单篇**（约 15–22KB）后再 `setData`，远低于 1MB 限制。
- `app.json` 的 `preloadRule` 只在进入首页时预下载 `en1`，其余分包在首次进入对应卷种时按需下载。

## 五、常见问题

**Q：横屏没有生效 / 想改成竖屏？**
A：阅读方向由 `package*/pages/read/read.json` 的 `"pageOrientation": "auto"` 加上运行时 `wx.setPageOrientation` 控制。**阅读方向现可在「设置 → 阅读方向」里切换（默认横屏）**：关闭＝横屏精读（左题右文），打开＝竖屏阅读（**上下分栏，文章在上、题目在下，两块同时可见，中间分隔条可拖拽调高**）。真机请确认未锁定竖屏；开发者工具中可在模拟器右上角切换设备方向。部分机型 / 开发者工具不支持自动转向，此时手动旋转手机即可。

**Q：长按/双击取词没反应？**
A：请到「设置 → 取词」检查「取词模式」与「长按看释义」是否被关闭。

**Q：预览/上传报错 `preloadRule [pages/home/home] source size xxxKB exceed max limit 2MB`？**
A：这不是主包超限，是 `app.json` 里 `preloadRule` 的**预下载分包总量**超过了微信 2MB 上限。当前配置为首页只预载 `en1`（约 1.4MB，过线），`en2` 点开时按需下载。若以后加数据导致 en1 也超 2MB，删掉整个 `preloadRule` 即可（分包本来就会在首次点开时自动下载）。

**Q：完形填空的题干是空的？**
A：完形填空数据中 `stem` 为空、选项为填词，属正常情况，卡片标题会显示「第 N 题」，选项正常作答与解析。
